# Содержание проекта (для таблицы)

| Поле | Содержание |
|---|---|
| **Группа** | _ваша группа_ |
| **Студент** | _Фамилия И.О._ |
| **Тема проекта** | Клавиатурный тренажёр с биометрическим ML-античитом и адаптивным профилированием пользователей |
| **Согласован** | _да / нет_ |
| **Модель** | Античит (человек или бот): логистическая регрессия и многослойный перцептрон на numpy (ручной backprop), двунаправленная GRU с собственной реализацией ячейки на PyTorch. Биометрическая верификация: детектор Махаланобиса со shrinkage-ковариацией, Scaled Manhattan, сиамская GRU-сеть с triplet loss. Профилирование: k-means++, гауссова смесь (EM), эмпирическая байесовская модель латентностей биграмм. Бенчмарки: LogisticRegression, RandomForest, GradientBoosting, OneClassSVM, IsolationForest, KMeans из scikit-learn |
| **Датасет** | Собственный. Тайминги нажатий (keydown/keyup, мс) реальных пользователей, собираются через веб-версию тренажёра: калибровочная фраза ×10 и тексты, 3 сессии в разные дни, анкета о стиле печати. Негативный класс: боты 7 типов, сгенерированные программно, плюс реальные попытки добровольцев со скриптами AutoHotkey/pynput в «режиме читера» |
| **Особенности** | Признаки из сырых событий: время удержания, интервалы между нажатиями, перекрытия клавиш, энтропия и автокорреляция интервалов, согласованность таймингов с геометрией клавиатуры (палец/рука), привязка к сетке системного таймера. Эмпирический Байес (иерархическая нормальная модель, метод моментов) для оценки слабых биграмм по малому числу наблюдений; по ним генерируются адаптивные упражнения. Валидация с разбиением по пользователям (GroupKFold) и по сессиям, проверка обобщения на неизвестный тип бота (leave-one-type-out). Метрики ROC-AUC, TPR при FPR = 1%, EER, силуэт, ARI |
| **Разделение работы** | — (индивидуальный проект) |
