# Как собрать реальные данные читеров

Все прогоны делаются в **режиме читера**: `https://<сайт>/?cheat=1`. Там лимита сессий нет, а все попытки помечаются `mode=cheat` (класс «читер» в датасете). Перед сессией выберите в выпадающем списке, чем читерите. Для каждого способа желательно 2–3 сессии с **разными параметрами**: разнообразие важнее количества.

| Тип в списке на сайте | Чем делать | Как |
|---|---|---|
| AutoHotkey / макрос-скрипт | `autotype.ahk` (AutoHotkey v2) | двойной клик по файлу → «Скопировать текст задания» → F8 |
| pyautogui / pynput / xdotool | `cheat_bot.py` | `pip install pynput`, затем по очереди режимы `const`, `uniform`, `gauss`, `timer`, `humanized`, `smart` с разными `--dd 80…250` и `--hold 30…120` |
| запись и воспроизведение своей печати | `cheat_bot.py record`, затем `cheat_bot.py replay` | сначала обычным образом напечатать 300+ символов (F9 — сохранить), потом воспроизводить запись на заданиях |
| макросы клавиатуры (софт производителя) | Razer Synapse, Logitech G Hub, Bloody и т. п. | записать макрос набора фразы и проиграть его; подходит только для калибровочной фразы, так как текст фиксированный |
| печатает другой человек | друг под **вашим** кодом | в обычном режиме это проверка биометрии; в режиме читера — размеченный пример «не владелец аккаунта» |
| другое | `js_console_bot.js` | вставить в консоль браузера (F12). Ловится правилом `isTrusted=false`, не ML |

Сколько нужно: минимум ~30 попыток на тип (2–3 сессии по 10 заданий), всего 200–300 читерских попыток. Сгенерированные боты из `keyml/bots.py` добавляются к ним автоматически.

`cheat_bot.py` нажимает **физические клавиши** через ОС (Windows), поэтому раскладка должна совпадать с языком задания. После первого задания посмотрите строку «вероятность читерства …» под полем ввода: ответ сервера на попытку должен прийти.
